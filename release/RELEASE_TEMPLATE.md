## Install
Download the signed APK from Assets. Enable HyperGesture in LSPosed/Vector for System launcher and System UI, then reboot.

From version 0.4.4 onward, open **App updates** to check and download updates inside HyperGesture. Allow notifications for background alerts. Android may delay the scheduled checks. Confirm installation in Android, then reboot to load the new hooks.

Requirements: Android 15, MiuiHome versionCode 601052343, SystemUI versionCode 202408080. Keep the system launcher installed.
